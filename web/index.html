About
The model is a fully-convolutional re-wrap of the patch-based update network trained in main.ipynb. Weights are copied 1:1; the 3×3 valid-padded conv becomes a 3×3 same-padded conv on the full grid, and the Dense head becomes a 1×1 conv. Both forms are mathematically identical. Inference runs entirely on the GPU via WebGL.
Powered by ONNX Runtime Web. See export/export_to_onnx.py for the conversion pipeline.
